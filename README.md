# Music Collection Cleaner (MCC)

**Version: 0.5.123**

Finds the best combination of releases in your music collection and removes unnecessary repeated songs, keeping every wanted unique recording.

## Download and run

1. Download the `.pyw` file from the **[latest release](https://github.com/karpuzikov/MCC/releases/latest)**.
2. Double-click it.

Needs Windows 11 and Python 3.

## What it does

Music collections fill up with the same songs on deluxe editions, singles, remasters and compilations.

MCC finds them and keeps the smallest set of releases that still has every song you want. Songs are matched by how they sound, not by their names. You see its choices on a map, and you decide what to copy or move.

## Safety

Analysis never changes your files. Copy and Move run only when you click them. Use **Copy** first.
