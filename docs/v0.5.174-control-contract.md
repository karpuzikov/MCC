No newly added duplicate action, nested menu, or modal is permitted. Focus and keyboard targets must remain discoverable, with reduced-motion respected for animations. All controls use the shared stylesheet, design tokens, icons, and 24px button system.

## Process lifecycle and invalidation
- Full Scan: read files/metadata, verify audio integrity, identify excluded categories, score sources, fingerprint candidates, compare acoustic identities, optimize release set, build map. It is expensive by definition and still runs when audio or dependencies changed.
- Classification-only Re-scan: validate the file signature (path, byte size, mtime_ns, ctime_ns) of previously verified audio/CUE files, re-evaluate policy using retained evidence, update wanted group membership, re-optimize. **No FFmpeg full decoding, Chromaprint generation, pairwise comparison or padding verification** on this path. A newly included unverified track is blocked until full Scan.
- Copy: validate file signatures again before beginning, preserve original audio and map, surface destination path and progress; retain undo/journal semantics.
